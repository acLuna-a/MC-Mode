# MC-Mode

存放若干 Minecraft 模组（1.20.x / Forge）的仓库。每个模组占一个独立目录，内含成品 jar 与说明；附带源码的模组连工程一并收录。

| 模组 | modId | 版本 | 目录 |
| --- | --- | --- | --- |
| Maid Flight / 女仆飞行 | `maid_flight` | 1.2.1 | [`maid-flight/`](maid-flight/) |
| 神创-三叉戟-神 / Godforged Trident | `god_trident` | 1.0.0 | [`god-trident/`](god-trident/) |

## 共同环境要求

| 项目 | 要求 |
| --- | --- |
| Minecraft | 1.20 / 1.20.1 |
| 模组加载器 | Forge（loader 46 及以上） |
| 前置模组 | 车万女仆（`touhou_little_maid`）1.5.3 及以上 |

## 安装

进入对应模组的目录，下载其中的 `.jar`，放进游戏目录下的 `mods` 文件夹。
