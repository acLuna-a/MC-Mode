# Maid Flight / 女仆飞行

为车万女仆（Touhou Little Maid）添加飞行能力的 Forge 模组。安装后，已驯服的女仆可以开启飞行模式，并跟随主人穿越空中；同时附带调节飞行扫帚速度的功能。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| Minecraft | 1.20 / 1.20.1 |
| 模组加载器 | Forge（loader 46 及以上） |
| 前置模组 | 车万女仆（`touhou_little_maid`）1.5.3 及以上 |

## 下载

| 文件 | 版本 |
| --- | --- |
| `maid-flight-1.2.1.jar` | 1.2.1 |

把 jar 放进游戏目录下的 `mods` 文件夹即可。

## 玩法

- **女仆飞行羽翼**：右键已驯服的女仆切换飞行模式，只有主人可以切换。
- **扫帚调速器**：右键飞行扫帚调整飞行速度。
- **飞行道具书**：飞行相关的道具书。

飞行模式下落地免伤生效；飞行中的女仆可以跟随主人穿越空中。

## 合成配方

**女仆飞行羽翼**

```

GEG
 F
```


**飞行道具书**

```
 P
PBP
 P
```
